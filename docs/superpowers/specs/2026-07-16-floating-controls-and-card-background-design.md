# 悬浮控制与卡片背景调整

## 目标

- 语言与主题控制在页面任意滚动位置都可使用。
- 首页卡片不再透出整页背景的点阵，明暗主题均保持清爽。

## 设计

- 复用现有 `PageHeaderControls`，通过 React Portal 挂到 `document.body`，避开页面过渡容器对 `position: fixed` 的影响。
- 控制组改为右下角横向悬浮胶囊，并为移动端保留安全区间距；现有语言、主题按钮及无障碍标签不变。
- 仅提高首页主要玻璃卡片的背景不透明度，保留边框、渐变和悬停效果；整页背景的星点、树叶与火焰效果不变。

## 验证

- 回归检查控制组使用 Portal 且定位在右下角。
- 回归检查明暗主题卡片背景不再使用会明显透出点阵的低透明度。
- 运行现有 Node 回归测试、TypeScript 校验和 Next.js 生产构建。
